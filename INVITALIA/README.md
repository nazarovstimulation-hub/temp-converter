# INVITALIA.co

Все материалы проекта в одной папке.

```
INVITALIA/
├── site/                 сайт, открывается без сборки
│   ├── index.html        главная страница
│   ├── editor.html       редактор приглашения с живым предпросмотром
│   ├── CNAME             домен для GitHub Pages
│   └── assets/           логотип: полный, значок, надпись
└── logos/                10 ранних концептов логотипа (SVG) и их презентация
```

## Как открыть локально

Дважды щёлкните `site/index.html` или `site/editor.html`. Шрифты и
библиотека QR-кода подгружаются из интернета, остальное работает офлайн.

## Где хранятся данные редактора

- Черновик автоматически сохраняется в браузере (localStorage), включая
  тестовые ответы гостей из предпросмотра.
- Кнопка **Экспорт** выгружает все данные в файл `invitalia-<ссылка>.json`.
  Кладите такие файлы в эту папку, например в `INVITALIA/drafts/`.
- Кнопка **Импорт** загружает JSON обратно в редактор.

## Публикация на домене invitalia.co (домен у Wix)

1. GitHub → репозиторий → Settings → Pages → Source: **GitHub Actions**.
   Workflow `.github/workflows/pages.yml` уже публикует папку `site/`.
2. Там же в поле Custom domain впишите `invitalia.co`, включите Enforce HTTPS
   после выпуска сертификата.
3. Wix → Domains → invitalia.co → Manage DNS Records:

   ```
   A      @     185.199.108.153
   A      @     185.199.109.153
   A      @     185.199.110.153
   A      @     185.199.111.153
   CNAME  www   nazarovstimulation-hub.github.io
   ```

   Если к домену подключён сайт Wix, отключите его от домена.
