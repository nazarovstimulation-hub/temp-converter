# INVITALIA.co — 10 концептов логотипа

Десять знаков для онлайн-платформы электронных свадебных приглашений.
Каждый концепт построен на одном запоминающемся значке, который читается
и в размере фавиконки (16 px), и на крупных носителях.

Откройте `index.html` в браузере: там каждый знак показан на фирменной
плашке, в лок-апе с надписью, в палитре и в монохроме (48 / 32 / 16 px).

| № | Файл | Концепт | Идея значка |
|---|------|---------|-------------|
| 01 | `01-sigillo.svg` | Sigillo | Сургучная печать с монограммой I и хвостиком пузыря сообщения |
| 02 | `02-cipressi.svg` | Cipressi | Два кипариса склоняются друг к другу, в просвете между ними сердце |
| 03 | `03-arco.svg` | Arco | Конверт, верх которого превращён в романскую арку с замковым камнем |
| 04 | `04-campanile.svg` | Campanile | Колокольня-буква I с колоколом и бейджем уведомления у шпиля |
| 05 | `05-anello.svg` | Anello Sì | Обручальное кольцо, в котором камень заменён на галочку RSVP |
| 06 | `06-cuore-qr.svg` | Cuore QR | Сердце, собранное из модулей QR-кода с поисковыми метками |
| 07 | `07-ramo.svg` | Ramo Segnale | Дуги сигнала Wi-Fi, выложенные оливковыми ветвями |
| 08 | `08-brindisi.svg` | Brindisi | Два фужера образуют V, пузырьки над ними как индикатор «печатает» |
| 09 | `09-pin.svg` | Pin Invito | Маркер карты с конвертом внутри |
| 10 | `10-maiolica.svg` | Maiolica | Плитка амальфитанской майолики с монограммой I |

Для каждого концепта есть две версии:

- `NN-name.svg` — цветной знак на фирменной плашке 240×240 со скруглением;
- `NN-name-mono.svg` — одноцветный знак без плашки (чёрный на белом) для
  печати, гравировки и фавиконок.

Шрифты надписей (Google Fonts) указаны на странице рядом с каждым
концептом. Перед использованием в продакшене надпись стоит перевести в
кривые, чтобы логотип не зависел от установленных шрифтов.
