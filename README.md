# INVITALIA

Este repositorio contiene **INVITALIA**, el servicio de invitaciones digitales para bodas y eventos (carpeta `INVITALIA/`). El sitio de `INVITALIA/site/` se publica en GitHub Pages con el workflow `.github/workflows/pages.yml` en cada push a `main`.

Configuración única en GitHub: Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Fiestalia

El proyecto hermano **Fiestalia** (álbum de fotos QR para eventos) vive en su propio repositorio: https://github.com/nazarovstimulation-hub/fiestalia

---

El repositorio conserva además la utilidad original `temp_converter.py` (conversión Celsius/Fahrenheit) con sus tests: `pip install -r requirements.txt && pytest`.
